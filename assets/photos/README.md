# Profile photos

1. Drop image files here (`jpg`, `png`, or `webp`).
2. Name them clearly, e.g. `rebecca-newcastle.jpg`.
3. In `data/org-chart.xlsx`, set the **photo** column to that filename  
   (example: `rebecca-newcastle.jpg`) **or** a full `https://…` URL.
4. Commit and push — the chart picks them up on the next Pages deploy.

Leave **photo** blank to keep the square placeholder.
